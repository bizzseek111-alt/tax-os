# Phase 5 — Question Reduction & Minimization Architecture

## 1. Executive Summary: "Questions to File"

Legacy tax software interrogates taxpayers with dozens or hundreds of exhausting questions (e.g. asking a single filer about 19 different types of foreign maritime income). 

Autonomous Tax OS inverts this dynamic through the **QuestionReductionAgent**:
- **Baseline**: 0 unnecessary questions asked.
- **Deduction Inference**: Derives 90%+ of required facts directly from ingested documents, OCR feeds, and bank transactions.
- **Maximum Threshold**: Targets fewer than **5 essential questions** to file a complete individual or Schedule C tax return.

---

## 2. The 4-Stage Reduction Pipeline

```mermaid
flowchart LR
    A[Unresolved Tax Uncertainties] --> B[1. Evidence Inference]
    B --> C[2. Materiality Filtering]
    C --> D[3. Question Bundling]
    D --> E[4. Conservative Fallback]
    E --> F[< 5 User Questions]
```

### Stage 1: Automated Evidence Inference
Before asking the taxpayer any question, the agent searches for existing indirect facts:
- Instead of asking *"Do you have a health savings account?"*, checks Box 12 Code W on W-2 forms.
- Instead of asking *"Did you pay real estate taxes?"*, checks Box 10 on Form 1098 mortgage statements.

### Stage 2: Materiality Filtering
Uncertainties with tax impact below **$50.00 USD** are not presented as blocking questions. They are either absorbed into standard calculations or handled via safe harbors (e.g., standard deduction vs non-qualifying itemized list).

### Stage 3: High-Context Question Bundling
Related queries are grouped into a single multi-choice prompt:
- Example: Instead of 4 separate questions regarding business vehicle usage, presents a single prompt:
  *"Did you drive your vehicle for business meetings in 2026? If so, select your estimated business mileage range or upload your mileage log."*

### Stage 4: Conservative Statutory Fallback
If the user skips an optional inquiry, the agent applies the **Statutorily Safe Conservative Election**:
- Example: If a taxpayer cannot document actual home office expenses, defaults to the **Simplified Method ($5/sq ft up to $1,500)** rather than blocking the filing.

## 3. Structured Question Contract

Questions generated by the engine adhere to a strict interactive contract:

```typescript
export interface TaxpayerQuestion {
  questionId: string;
  category: 'INCOME' | 'DEDUCTION' | 'RESIDENCY' | 'DOCUMENT';
  prompt: string;
  contextExplanation: string; // Plain-English rationale ("Why we're asking")
  dollarImpactEstimate: number; // Potential tax dollar difference
  responseType: 'YES_NO' | 'DOLLAR_AMOUNT' | 'DOCUMENT_UPLOAD' | 'MULTIPLE_CHOICE';
  options?: string[];
  safeDefaultAction: string; // What happens if skipped
  sourceAgent: AgentType;
}
```
