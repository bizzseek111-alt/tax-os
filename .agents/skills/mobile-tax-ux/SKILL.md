# Mobile Tax Ux Skill

## 1. Overview
Delivers an ergonomics-first mobile interface for receipt capture, tax notifications, and rapid question resolution.

## 2. Core Responsibilities
Provides camera-driven document scanning, binary card-swipe question resolution, and filing tracking while preventing overcrowded tax form views on compact mobile screens.

## 3. Principles & Invariants
- Target WCAG 2.2 AA accessibility standards.
- Never show raw unverified AI output as definitive tax authority.
- Maintain high visual trust, clear typography, and tabular numeric alignment.
- Prioritize user agency, explainability, and progressive disclosure at all times.
