# Design System Skill

## 1. Overview
Enforces UI token consistency, typography, financial spacing, and component invariants across Autonomous Tax OS.

## 2. Core Responsibilities
Coordinates color palettes, typography scales, elevation tokens, border treatments, and responsive layouts. Ensures no hardcoded ad-hoc styles bypass the design token system.

## 3. Principles & Invariants
- Target WCAG 2.2 AA accessibility standards.
- Never show raw unverified AI output as definitive tax authority.
- Maintain high visual trust, clear typography, and tabular numeric alignment.
- Prioritize user agency, explainability, and progressive disclosure at all times.
