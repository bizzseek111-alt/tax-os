# Consumer Tax Ux Skill

## 1. Overview
Governs the B2C taxpayer journey, minimizing Questions to File (QtF) and maximizing financial clarity and calm.

## 2. Core Responsibilities
Ensures the application works first and the user responds second. Replaces traditional 80-step wizards with action-oriented progressive disclosure and dynamic completion tracking.

## 3. Principles & Invariants
- Target WCAG 2.2 AA accessibility standards.
- Never show raw unverified AI output as definitive tax authority.
- Maintain high visual trust, clear typography, and tabular numeric alignment.
- Prioritize user agency, explainability, and progressive disclosure at all times.
