# Professional Tax Ux Skill

## 1. Overview
Structures high-density, exception-first interfaces for Enrolled Agents (EAs) and CPAs conducting tax return reviews.

## 2. Core Responsibilities
Focuses professional attention on exceptions, high-risk items, multi-state controversies, and substantiation audits, preventing redundant review of verified deterministic calculations.

## 3. Principles & Invariants
- Target WCAG 2.2 AA accessibility standards.
- Never show raw unverified AI output as definitive tax authority.
- Maintain high visual trust, clear typography, and tabular numeric alignment.
- Prioritize user agency, explainability, and progressive disclosure at all times.
